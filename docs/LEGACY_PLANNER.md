# Legacy Professions planner

WayForth includes the WoWForever Fortune Professions-tree planner: seven perks, a 16-point character plan, prerequisite and tier checks, a five-point gathering preset, a 16-point all-rounder preset, and per-character SavedVariables.

This is a planning tool. It does not spend or reset Legacy points in game, read the live Legacy tree, or represent the other two Legacy trees. Its perk descriptions and thresholds were carried over from Forever Fortune's pre-launch reference and need verification against the live character before relying on them.

The planner prevents allocating over 16 points, spending into locked tiers, or removing points that would invalidate an invested prerequisite. Reset only clears the WayForth plan for the current character.
