# WayForth Forever 1.1b3

**Beta • WoW Forever 1.60.1 • Interface 16001**

## Leveling Guide Improvements
- Cleaned up duplicate guide listings and overlapping full-zone and chapter entries.
- Improved zone recommendations so the same zone is not suggested repeatedly.
- Expanded Alliance and Horde quest coverage, including missing Elwynn Forest quests and Westfall flight-path quests.
- Expanded the Skyborne starting experience with missing quest phases, faction-specific branches and class introductions.
- Repaired several quest prerequisite chains and improved pickup, objective and turn-in progression.

## Navigation and Stability
- Added faction-aware fallback locations from independently observed Forever quest data.
- Improved missing minimum-level metadata and prevented unusable guides from replacing the active guide.
- Preserved existing guide IDs and saved character progress.

## Testing
- Automated QA passed, including guide progression, synchronization, navigation, saved progress and packaging.
- Owner reports the 1.1b3 preview is working in-game.

## Known Beta Limitations
- Exhaustive quest eligibility, optional/class quest coverage and comprehensive in-game QA pending.
- Existing Engineering skill 52–54 and First Aid skill 45–49 and 75–79 gaps remain (#55, #56).
- Profession guides remain unchanged.
