# WayForth Forever 1.0b11

### Profession Guide Improvements
- Improved profession leveling recommendations using recipes your character already knows.
- Prioritized orange recipes, followed by yellow recipes, to help maximize skill gains.
- Displayed required materials and current inventory quantities for recommended crafts.
- Updated recipe recommendations automatically as profession skill increases.
- Preserved the latest crafting recommendation when the profession window closes.

### Interface Improvements
- Improved dashboard category spacing and responsiveness.
- Refined Recently Used guide layouts for better readability.
- Removed unnecessary map pins from crafting steps.
- Retained trainer navigation when verified locations are available.

### Compatibility
- **Game:** World of Warcraft Forever
- **Client:** 1.60.1
- **Release channel:** Beta
